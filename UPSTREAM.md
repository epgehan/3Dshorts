# Upstream and authority

Baseline repository: https://github.com/mromidev/claude-animated-shorts

Inspected baseline commit: `e3b817b6afc6cd413466d43f11ba31209e034bbf`.

The13 files under `templates/bridge/` (excluding this package's addedREADME) are unchanged implementation references from that MIT-licensed baseline. `references/source-guides/LEGACY_SKILL.md` preserves its original instructions for comparison. The upstream copyright/permission notice is retained in `LICENSE`.

The user-provided reference-image guide is saved at `references/source-guides/USER_DESIGN_GUIDE.md`, sourced from https://github.com/epgehan/3D-video/blob/main/videos/salme/DESIGN_GUIDE.md. Its earlier vertical/caption statements are historical project guidance; current explicit user instructions and the active v2skill take precedence.

This package adds the seven-upload study, source-backed topic reports, analysis/review/installation tooling, a new Arial subtitle overlay and refined production instructions. It does not copy the upstream reference frames/sheets or publish the seven uploaded videos, their extracted images or their soundtracks. Filenames, hashes, quantitative diagnostics and written observations are included for reproducibility.

The new file name is `cartoon-3d-short-v2` so it can be installed alongside the baseline rather than silently overwriting it. No claim is made that original third-party authoring rigs, source code or exact pixels have been recovered. No new short was rendered as part of this research-only delivery; the bridge scaffold and caption overlay require a configured host project and production validation.
