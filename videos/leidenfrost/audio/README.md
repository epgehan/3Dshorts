Original audio for the 15-second Leidenfrost short. `audio.wav` is the exact 15-second, 48 kHz stereo production master; `audio.mp3` is the browser playback copy. Mia uses Kokoro `af_heart`; Leo uses `am_michael`. These are authorized synthetic voices, not impersonations. All procedural sound effects are generated from a fixed seed; there is no music or reference recording.

Build in an isolated Python environment with requirements.txt, FFmpeg, and the neural assets downloaded from https://github.com/thewh1teagle/kokoro-onnx/releases/tag/model-files-v1.0 . Place `kokoro-v1.0.onnx` and `voices-v1.0.bin` under `/tmp/leidenfrost-models`, or set `KOKORO_MODELS`. Run `python build_audio.py`. The `lineN-raw.wav` files retain original TTS; `lineN.wav` files are the normalized and, only where necessary, pitch-preserving compressed dialogue stems.

Run `python align_captions.py` with the local whisper.cpp installation to regenerate ASR/DTW evidence. Word boundaries are approximations derived from the actual audio, not uniform transcript spacing. `alignment-review.json` records approved word timing. `make_captions.py` converts reviewed times into nonoverlapping half-open 30fps cue intervals. The dialogue transcript is authoritative when ASR spelling differs. Actual Arial white text with a black outline must be applied by the renderer after scene effects.

`verification.json` records the measured final WAV loudness/peak and segment placements. MP3 container duration may include encoder delay; playback uses its gapless delay metadata. Video muxing should use the WAV master.
